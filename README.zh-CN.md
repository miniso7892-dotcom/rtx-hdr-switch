# RTX HDR 开关（Chrome / Edge 扩展）

[English](README.md) | 简体中文

按视频控制 NVIDIA「RTX 视频增强」的 HDR（RTX Video HDR / TrueHDR）：想要高亮度的视频保持 HDR，白底、纯白、长时间观看的视频切回 SDR。支持快捷键、记住每个视频的选择、自动识别白底视频、夜间护眼和连续观看提醒。

> **注意：关闭 HDR 时，该视频的 RTX 超分（VSR）也会一起关闭。** 这是 Chrome 的限制，页面层面没有办法只关其中一个。
>
> **扩展只能「关掉」RTX HDR，不能「打开」它。** RTX HDR 本身要在 NVIDIA App 里全局开启，扩展做的是对不想要 HDR 的视频把它挡掉。

## 原理

Chrome 只有在视频被提升为 DirectComposition overlay 时才会调用 NVIDIA 视频处理器。扩展在需要关闭的 `<video>` 元素上加一条内联样式 `filter: brightness(0.9999) !important`（页面自己给视频加了 filter 时，叠加在它后面），视频就不再走 overlay，RTX HDR 和超分随之关闭；开启时把页面原来的内联 `filter` 还原。8 bit 画面上看不出这个滤镜的差别，切换实时生效，不需要刷新页面，窗口和全屏都有效。

实测（Chrome 155 + NVIDIA 驱动 617.42，FP16 桌面抓取）：RTX HDR 生效时画面白色约 1000 尼特；加上滤镜后降到 Windows 的 SDR 白（由「SDR 内容亮度」决定），去掉滤镜立即恢复。设计细节和源码依据见 [SPEC.md](SPEC.md)。

## 使用前提

- NVIDIA App 里打开了「RTX 视频增强」的 HDR：NVIDIA App → **系统** → **视频** → **RTX 视频增强**（超分按需打开）。
- Windows 的 HDR 已开启（设置 → 系统 → 屏幕 → 使用 HDR）。
- 浏览器开启了硬件加速：
  - Chrome：`chrome://settings/system` → 「使用图形加速功能（如果可用）」
  - Edge：`edge://settings/system` → 「在可用时使用图形加速」
  
  改完需要重启浏览器。

## 安装

0. 获取代码：`git clone` 本仓库，或在 GitHub 页面点 **Code → Download ZIP** 下载后解压，放到一个长期不动的位置。
1. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开开发模式：
   - Chrome：右上角的 **开发者模式**
   - Edge：左侧栏的 **开发人员模式**
3. 加载扩展：
   - Chrome：点击 **加载已解压的扩展程序**
   - Edge：点击 **加载解压缩的扩展**
   
   然后选择 `rtx-hdr-switch` 文件夹（里面直接就有 `manifest.json` 的那一层；ZIP 解压后可能多套了一层同名文件夹）。
4. 建议把扩展固定到工具栏（点工具栏上的拼图图标 → 图钉），方便看角标。

说明：

- **安装后不要移动、重命名或删除这个文件夹。** 浏览器每次启动都从这里读取扩展，文件夹不在了扩展就会失效。要换位置的话，先在扩展管理页「移除」，挪好文件夹后再重新加载。
- Google Chrome 稳定版会忽略 `--load-extension` 命令行参数，只能用上面的方法安装。
- 安装（或更新、重新加载）扩展时，已经打开的 http/https 页面会被自动注入脚本，一般不用刷新。如果某个页面没有反应（例如注入失败、页面在安装时处于休眠状态），**刷新一下该页面**即可。
- 本地文件（`file://`）需要在扩展详情页打开「允许访问文件网址」后再刷新页面。

## 验证是否生效

角标只说明扩展有没有挡住 RTX HDR，不能证明 NVIDIA 真的在处理视频。第一次用时建议这样确认一次：

1. 打开 NVIDIA App → **系统** → **视频**，把窗口放在浏览器旁边。
2. 在浏览器里播放一个普通（非会员、非付费）的视频，例如 YouTube 或 B 站的视频，保持窗口化播放即可。
3. 看 NVIDIA App 里「RTX 视频增强」下 HDR 一项的 **状态**：扩展显示「HDR 开」时应为激活状态（不同版本的字样可能是「已激活」或「活动」）。
4. 按 `Alt+H`（或在弹窗里点「切换」）切到「HDR 关」：几秒内状态应变为未激活，画面里的白色也会明显变暗（从 RTX HDR 的高亮度降到 Windows SDR 白的亮度）。
5. 再按一次 `Alt+H`，状态回到已激活，白色重新变亮。

如果第 3 步一开始就是未激活，说明 RTX HDR 本身没有生效，和扩展无关：检查上面的「使用前提」（尤其是浏览器硬件加速和 NVIDIA App 里的开关），或者换一个视频试试（受版权保护的视频本来就不走这条路径）。

## 使用

### 角标

工具栏图标上的角标显示当前标签页主视频的状态：

- 绿色 **HDR**：扩展没有阻止 RTX HDR（实际是否生效以 NVIDIA App 里的状态为准，见上面的「验证是否生效」）
- 灰色 **SDR**：扩展已为这个视频关闭 RTX HDR
- 深黄色 **DRM**：受版权保护的视频，扩展无法控制（多见于会员影视）
- 无角标：没有检测到视频

### 快捷键

| 快捷键 | 作用 |
|---|---|
| `Alt+H` | 切换当前视频的 RTX HDR（记为「手动」，默认会记住） |
| `Alt+Shift+H` | 开/关 自动检测白底视频 |
| 未设置 | 清除当前视频的记忆（恢复按规则决定） |

快捷键只在浏览器窗口有焦点时生效。可以在弹窗里点「修改快捷键」，或打开 `chrome://extensions/shortcuts`（Edge 为 `edge://extensions/shortcuts`）修改；如果和其他扩展冲突，浏览器可能不会分配建议的按键，需要在这里手动设置。

切换时视频左上角会显示一个小提示，例如「RTX HDR：开（手动）」「RTX HDR：关（自动检测·白底）」。

### 弹窗

- **当前视频**：显示 HDR 开/关和原因，「切换」按钮、「清除此视频记忆」按钮，视频的识别 key，以及自动检测最近测到的画面亮度和白色占比。
- **本网站**：跟随规则 / 总是开 HDR / 总是关 HDR。
- **自动检测白底/高亮视频**：关闭 / 只自动关闭（推荐）/ 自动开关，灵敏度低 / 中 / 高。
- **夜间护眼**：在设定时段（支持跨午夜，如 23:00–07:00）内默认关闭 HDR。
- **连续观看提醒**：累计看 HDR 视频的时间，到设定分钟数时提示休息，可选「到时自动切回 SDR」。0 表示关闭。详见下面的「连续观看提醒」。
- **默认（没有任何规则时）**：开或关。
- **其他**：手动切换后记住此视频、显示屏幕提示。
- **快捷键**：列出当前绑定。

### 决策顺序

每个视频按下面的顺序取第一个命中的规则（弹窗里的「原因」就是命中的那一条）：

1. **手动**：本次打开页面后对这个视频手动切换过（「护眼提醒」自动切回 SDR 也属于这一级，但不会被记住）。
2. **已记住此视频**：之前手动切换并记住的选择。
3. **网站规则**：弹窗里「本网站」的设置（视频在别的网站的嵌入播放器里时，以当前标签页这个网站的设置为准）。
4. **夜间护眼**：处于夜间时段时关闭。
5. **自动检测(白底)**：画面判定为白底/高亮时关闭。
6. **默认**。

视频按网站识别：YouTube（含频道直播嵌入）、Bilibili（含分 P、番剧、直播、嵌入播放器）、腾讯视频、爱奇艺、Twitch（含剪辑）用视频 ID 识别；其他网站用「去掉跟踪参数后的网址」识别。最多记住 2000 个视频，超出时自动删除最旧的。

YouTube 小窗、Twitch 迷你播放器：从视频页跳到首页、目录等页面时，小窗里继续播放的视频仍按原来那个视频处理（记忆、手动选择都保留）。

### 自动检测白底视频

主视频开始播放时立刻取一帧，之后每 1.5 秒取一帧，缩小到 64×36 计算平均亮度和白色像素占比，连续 3 帧偏亮就关闭 HDR（大约 3 秒）。

- **只自动关闭**：判定为白底后，这个视频在本次打开期间保持关闭，中途插播广告、换清晰度、在弹窗里改灵敏度都不会让它闪回 HDR。
- **自动开关**：连续 6 帧明显偏暗后重新开启；每次自动切换后至少保持 10 秒，避免来回闪。
- 全黑的帧（转场、加载）不计入。
- 只有在「手动 / 已记住 / 网站规则 / 夜间」都没有命中时才会检测；暂停、切到后台时不检测。

### 连续观看提醒

- 累计的是「正在看、而且 HDR 没被关掉」的时间：**换视频、自动连播、开新标签页都接着算**，暂停、切到后台、SDR 状态下的时间不算。
- **停止看视频超过 5 分钟**（暂停、关掉页面都算）才清零重新计时。
- 到时在视频上提示「已连续观看 HDR N 分钟，休息一下眼睛吧」，提示后重新计时。
- 勾选「到时自动切回 SDR」时，提示变为「……已切回 SDR，休息一下眼睛吧（按 Alt+H 可恢复 HDR）」，并且之后看的视频（下一个视频、其他标签页）也都保持 SDR，直到：停止看视频超过 5 分钟、你按快捷键或在弹窗里手动切回 HDR、或者在弹窗里关掉这个选项。

## 限制

- **只能关闭，不能开启**：NVIDIA App 里 RTX HDR 没开、浏览器没开硬件加速时，扩展显示「HDR」也不会有 HDR。
- **关闭 HDR 会同时关闭该视频的 RTX 超分**（Chrome 限制）。
- **受版权保护（DRM）的视频无法控制**：这类视频走 MediaFoundation overlay，CSS 影响不到；角标显示「DRM」，弹窗显示「受版权保护的视频，无法控制」，也无法检测画面亮度。护眼计时照样累计。
- **画中画**窗口里的视频可能不受控制（浏览器直接把视频画面送进画中画窗口）；回到页面内播放后生效。弹窗会提示。
- **跨域且没有 CORS 的视频**无法读取画面，自动检测不可用，弹窗会提示；手动切换、记忆、网站规则不受影响。
- 少数页面会不停把视频的样式改回去：扩展会让步，弹窗原因显示「页面不断改写视频样式，无法关闭」，之后隔一段时间再试；你手动切换时也会马上再试。
- 页面自己已经给视频加了 `filter`（例如某些播放器的「画面调节」）时，视频本来就不会走 overlay，RTX 本来就不生效；扩展关闭期间会把自己的滤镜叠加在后面，页面的效果保留，开启后还原。
- 视频本身全屏（`video.requestFullscreen()`）时屏幕提示被浏览器的全屏层挡住，看不到；网站自己的播放器全屏没有这个问题。
- `chrome://`、扩展商店等浏览器内部页面无法使用。
- 快捷键只在浏览器窗口有焦点时生效。

## 故障排查

| 现象 | 处理 |
|---|---|
| 弹窗显示「还没有连接到此页面」 | 刷新页面。安装前打开、处于休眠状态的标签页可能没有被自动注入。 |
| 弹窗显示「此页面没有检测到视频」或「……正在显示的视频」 | 确认视频已经出现在页面上；有的网站要先点播放才创建视频。 |
| 弹窗显示「视频不在可见区域内」 | 视频滚出了窗口，滚回来即可。 |
| 角标是绿色 HDR，但画面并不亮 / NVIDIA App 显示未激活 | RTX HDR 本身没有生效：按「使用前提」检查 NVIDIA App 开关、Windows HDR、浏览器硬件加速。 |
| 切到 HDR 关后画面亮度没变化 | 先按「验证是否生效」确认 RTX HDR 本身生效；DRM 视频、画中画无法控制。 |
| 按快捷键没反应 | 打开「修改快捷键」页确认已分配按键、没有和其他扩展冲突；确认焦点在浏览器窗口。 |
| 白底视频没有被自动关闭 | 确认自动检测没有被设为「关闭」、没有被更高优先级的规则（手动、记住、网站、夜间）覆盖；可以把灵敏度调高。跨域视频无法检测。 |
| 想恢复某个视频的默认行为 | 弹窗点「清除此视频记忆」，或给「清除当前视频的记忆」设置一个快捷键。 |
| 扩展突然失效、报错「无法加载」 | 检查 `rtx-hdr-switch` 文件夹是否被移动或删除。 |
| 更新扩展后页面行为异常 | 刷新页面。 |

## 开发

```
node test/lib.test.js        # 单元测试（决策、视频 key、自动检测、滤镜叠加、护眼累计、设置合并、manifest 校验）
python tools/make_icons.py   # 重新生成 icons/ 下的图标（需要 Pillow）
```

文件说明：`manifest.json`（MV3 清单）、`background.js`（service worker：角标、快捷键、护眼计时、安装时注入）、`lib.js`（纯逻辑，内容脚本、弹窗、service worker 和测试共用）、`content.js`（内容脚本）、`popup.*`（弹窗）、`SPEC.md`（设计规格与实测依据）。

## 隐私

扩展不联网、不收集任何数据。设置和「记住的视频」只保存在浏览器本地（`chrome.storage.local`），各标签页状态和护眼计时保存在 `chrome.storage.session`（浏览器重启清空）。自动检测只在本地把视频画面缩小到 64×36 计算亮度，不保存、不上传画面。
